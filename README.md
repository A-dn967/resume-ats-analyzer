
# 📄 Resume ATS Analyzer

An AI-powered Resume ATS Analyzer built using Streamlit and Google Gemini Flash.

Upload your resume, paste a job description, and receive an AI-generated ATS compatibility score with actionable recommendations.

## ✨ Features

- Upload resumes in PDF and DOCX formats
- Analyze resumes against job descriptions
- Generate ATS compatibility scores from 0 to 100
- Identify strengths and weaknesses
- Find missing keywords and skills
- Receive resume improvement recommendations
- Get professional formatting suggestions
- Generate an improved professional summary
- Download the analysis report

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini Flash
- Google Gen AI SDK
- PyPDF
- python-docx

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/resume-ats-analyzer.git
cd resume-ats-analyzer
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

## 🔑 Gemini API Key

Get your API key from Google AI Studio:

https://aistudio.google.com/apikey

Enter your API key in the application's sidebar.

## ☁️ Deployment

Deploy using Streamlit Community Cloud:

1. Push the project to GitHub.
2. Open https://share.streamlit.io/
3. Connect your GitHub account.
4. Select your repository.
5. Set the main file path to `app.py`.
6. Deploy the application.
